Privacy policy

Daystitch プライバシーポリシー

最終更新日：2026年10月22日

1. 収集する情報

Daystitch（以下「本アプリ」）は、開発者が利用者の個人情報を収集・保存することはありません。

ただし、利用者が設定で外部 AI（ChatGPT または Gemini）を選んだ場合に限り、AI 機能を使った時に必要な内容が、利用者ご自身の API キーで OpenAI または Google に直接送られます（「4. 第三者サービス」参照。開発者のサーバーは経由しません）。

2. 本アプリが扱うデータと保存場所

次のデータは、利用者の端末内と、利用者ご本人の iCloud（iCloud 同期をオンにしている場合）にのみ保存されます。開発者が閲覧・取得することはできません。

  • 予定、ToDo、習慣、日記（手書き・日記に貼った写真・テキスト・スタンプ・気分）、定型文
  • 手書き文字の認識結果（Apple の Vision フレームワークにより端末内で処理）
  • 録音した音声とその文字起こし・要約・議事録（音声は端末内に保存。文字起こしは初期設定では端末内で処理）
  • AI アシスタントの処理（初期設定は Apple Intelligence の端末内モデルで処理し、内容は端末の外へ送信されません。外部 AI を選んだ場合は 4 を参照）
  • 外部 AI の API キー（端末のキーチェーンにのみ保存。iCloud や開発者には送信しません）
  • デザインや使う機能などの設定（端末内のみ）

iCloud 同期は、Apple の CloudKit を通じて利用者本人のプライベートな領域に保存され、同じ Apple ID の端末間でのみ共有されます。設定画面からオフにできます。

3. 権限の利用目的

  • カレンダー：iPhone の「カレンダー」の予定を本アプリに重ねて表示するため（読み取りのみ。外部送信なし）
  • 位置情報：天気を表示するため。Apple の WeatherKit に位置を送信して天気を取得します。開発者は位置情報を受け取りません
  • 通知：予定・ToDo のリマインダーのため
  • カメラ：日記に貼る写真を撮影するため（撮影した写真は日記にのみ保存）
  • マイク・音声認識：日記ページで会議などを録音し、文字に起こすため（録音は利用者が操作した時のみ）
  • 写真への追加：日記ページを画像として「写真」に保存するため（利用者が操作した時のみ）
  • 写真の選択：日記に貼る写真を選ぶため。Apple の写真ピッカーを使用し、選んだ写真だけを受け取ります（写真ライブラリ全体にはアクセスしません）

4. 第三者サービス

  • Apple WeatherKit：天気情報の取得（Apple のプライバシーポリシーに従います）
  • Apple iCloud（CloudKit）：利用者本人の端末間でのデータ同期
  • Apple Intelligence（Foundation Models）：AI アシスタントの初期設定。端末内で動作し、外部の AI サービスにはデータを送りません
  • OpenAI（ChatGPT）／ Google（Gemini）：利用者が設定で選び、同意し、ご自身の API キーを入力した場合にのみ使用します。AI のボタンを押した時に、その処理に必要な予定・ToDo・日記・録音の文字（「録音の文字起こしも外部 AI で行う」をオンにした場合は録音の音声）が送信されます。送信された内容は各社のプライバシーポリシーと API 利用規約に従って扱われます（Gemini API の無料枠では、送信内容が Google のサービス改善に使われる場合があります）。設定でいつでも Apple Intelligence に戻せ、API キーも削除できます
  • OpenAI プライバシーポリシー: https://openai.com/policies/privacy-policy
  • Google プライバシーポリシー: https://policies.google.com/privacy
  • Apple Watch：iPhone から、ペアリングした利用者本人の Apple Watch に今日・明日の予定と今日の ToDo を送ります（Apple の WatchConnectivity による端末間通信。開発者には送信されません）
  • App Store / StoreKit：サブスクリプションの購入・管理（決済情報は Apple が管理し、開発者は受け取りません）
  • 広告・解析・トラッキングのサービスは使用していません

5. データの削除

アプリを削除すると、端末内のデータが削除されます。iCloud に同期したデータは、iPhone の「設定 › [ユーザー名] › iCloud › アカウントのストレージを管理 › Daystitch」から削除できます。バックアップファイルは利用者が保存した場所で管理されます。

6. お子様のプライバシー

本アプリの開発者は個人情報を収集しません。外部 AI の利用は任意で、各社の利用規約で定める年齢条件に従ってください。
